# How to Add the Next Case Study

My next case study will be added to the **Work / Case Studies** section of my portfolio using the same three-beat structure as my existing case studies.

### 1. Problem

Briefly explain the real problem the project was intended to solve, who it was for, and why it mattered.

### 2. What I Did

Explain my role, the technologies I used, the important decisions I made, and how I approached the problem. I will focus on my actual contribution rather than simply listing features.

### 3. What Came of It

Show the outcome using evidence such as a live demo, screenshots, GitHub repository, working features, or measurable results. I will also mention what I learned and what I would improve next.

### Steps to Add a Case

1. Finish the project and collect screenshots, demo links, and repository links.
2. Open my existing Claude Project containing my portfolio identity, voice, stack, and content structure.
3. Ask Claude to create the new case study using the existing three-beat format.
4. Review and correct the generated content so it accurately represents my real work.
5. Add the case study to the **Work / Case Studies** section of my portfolio.
6. Add the project link, GitHub link, and relevant visuals.
7. Check the case study on desktop and mobile.
8. Deploy the updated portfolio and verify that the new case study is accessible.
