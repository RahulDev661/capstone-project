# Capstone Project – AI-Assisted Development Setup

This repository contains the setup and configuration for my capstone project as part of the AI Engineering Internship program. The goal of this phase is to establish a modern AI-assisted development environment and adopt best practices for version control, project organization, and documentation.

## Cursor Rules

Project conventions live in `.cursor/rules/` and guide the Cursor AI agent:

- **`project-conventions.mdc`** — always active; Conventional Commits, async/await, tests in `/tests`
- **`nodejs.mdc`** — Node.js patterns for `.js` / `.ts` files
- **`express.mdc`** — REST API conventions for routes, controllers, services, and middleware
- **`mongodb.mdc`** — MongoDB/Mongoose conventions for models and data access
